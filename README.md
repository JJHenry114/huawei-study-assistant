# 学堂随课助手

在桌面版 Edge 或 Chrome 中使用。扩展跟随华为开发者学堂的页面控件播放视频、完成文字随堂练习，并可接续页面列出的下一课。

## 安装

1. 在 Edge 地址栏打开 `edge://extensions`，或在 Chrome 打开 `chrome://extensions`。
2. 开启“开发者模式”，点击“加载解压缩的扩展”或“加载已解压的扩展程序”，选择本项目的 **extension** 文件夹。该文件夹内应直接包含 `manifest.json`。
3. 打开扩展的“接口设置”，填写服务商提供的接口地址、模型名称和 API Key。地址可填写到 `/v1`，也可以直接填写到 `/chat/completions`。本机接口支持 HTTP localhost 和 127.0.0.1，远程接口使用 HTTPS。
4. 点击“测试连接”，允许访问所填接口。看到“连接成功”后点击“保存设置”。测试会向该接口发送一道示例题。

## 使用

打开[目标班级](https://developer.huawei.com/consumer/cn/training/classDetail/faa734fca6dd490f9ec6981b5302f238?type=1)，登录后点击扩展面板里的 **开始学习**，再从班级中选定一个课件。班级页的等待状态有效期为 15 分钟。也可以直接在已打开的慕课小节中点击开始。刚安装或更新扩展时，请先刷新已经打开的课程页。

- **视频播放方式**可在扩展面板中随时切换，选择会保存在本机，应用于正在运行的课件和后续小节。默认原速，可选 1.25、1.5、2、3、4、8、16 或 32 倍。32 倍优先使用播放器原生倍速。如果浏览器仅接受 16 倍且视频允许定位，扩展通过 16 倍播放配合分段跳转实现约 32 倍快进，面板会注明实际方式。
- **跳到最后一秒**会在视频时长和可定位范围就绪后，把进度条移至结束前一秒，再播放到结尾。自动打开的新课页面若被浏览器阻止有声播放，助手会尝试静音起播，可在播放器中恢复声音。
- **自动进入下一节或下一课**默认开启，可在面板中随时切换。视频播完并得到目录中的完成标记（如有），或随堂练习通过后，助手进入下一节。最后一节完成时，如果页面显示“下一课”卡片，助手会通过卡片上的“继续学习”入口打开新标签页。新页面会沿用播放和答题设置，遇到可识别的课程介绍页也会自动进入学习页。没有下一课入口时结束。关闭开关后，助手会在切换前等待。
- **文字练习**支持单选、多选和判断题。点击开始即启用自动提交，结果会写入当前登录账号的学习记录。AI 可能答错。平台显示未通过且开放重做时，扩展携带可见反馈重试一次。
- **暂停与继续**在扩展面板中操作。暂停会停止后续答题和切课，并暂停正在播放的视频。已发出的模型请求可能产生费用，其迟到的答案会被丢弃。
- **中断恢复**会先核对当前小节、上次提交和重试记录。同一课件由一个标签页运行。如果浏览器重启，或班级课件打开在独立的新标签页且没有自动接续，在课件页点击“继续学习”或“开始学习”。
- **获证提示**出现时，运行中的助手会识别“恭喜！您已获得《…》证书”和“查看证书”按钮，点击右上角的 ×。提示消失后，助手按自动切换设置继续。
- **页面需要人工操作**时，面板会给出原因。遇到图片题、主观题、独立考试、无法识别的课件或其他页面弹窗时，请根据页面提示操作，处理后再继续。上次交卷结果不明时，先确认页面上的作答记录。如果已经完成，可手动切到下一节后继续。

## 数据与适配

模型请求只包含题型、题干、选项及上一轮的可见答题反馈。API Key 保存在浏览器扩展的本机存储中，用于向你配置的模型接口认证。课件进度、题目标识和重试记录也保存在本机。卸载扩展会清除这些本地数据。

站点适配基于华为公开前端中的慕课目录、章节页脚、播放器、随堂练习和下一课卡片。扩展使用脚本权限读取站点按钮点击时生成的学堂课程地址，由后台打开目标标签页。测试在隔离浏览器内使用模拟课程和模型进行。真实账号下的播放器、练习配置和评分反馈可能因课件而异。

## 运行验证

使用 Node.js 22.4 或更高版本，在项目根目录运行 `node tests/browser.mjs`。脚本默认使用 Windows 标准安装位置的 Edge。其他安装位置可通过环境变量 `CHROMIUM_BIN` 指定支持加载未打包扩展的 Chromium 浏览器。

脚本使用临时浏览器配置、模拟课程和本机模型服务，运行结束后清理临时数据。测试覆盖接口设置、班级接续、视频暂停与结束、单题和整页提交、重试上限、无效答案、图片题、重复启动、双标签页、刷新恢复和暂停时的模型响应。
